# NESEREGASHOP

Telegram-магазин цифровых курсов с оплатой Telegram Stars, выдачей документов, SQLite, админ-панелью, историей заказов и возвратами.

## Установка

Требуется Python 3.10+.

```bash
python -m venv .venv
# Linux/macOS:
source .venv/bin/activate
# Windows:
# .venv\\Scripts\\activate
pip install -r requirements.txt
cp .env.example .env  # Windows: copy .env.example .env
```

Заполни `.env`: `BOT_TOKEN` от @BotFather, `ADMIN_IDS` (свой числовой Telegram ID), `SUPPORT_USERNAME` без @. `COURSE_STARS` — **цена в Telegram Stars**, а не рублях. Старый курс был заявлен за **199 ₽**; это **не** означает 199 Stars. Если `COURSE_STARS=0`, курс показывается в каталоге, но недоступен к оплате до настройки цены.

Запуск:

```bash
python bot.py
```

В `.env` поддерживаются переменные через python-dotenv. Не публикуй `.env` и `shop.sqlite3`.

## Администрирование

Напиши боту `/start` или `/admin`. В админ-панели можно создать курс (название → описание → цена Stars → файл-документ), поменять цену, заменить файл, скрыть/показать товар, увидеть статистику. Для исходного курса **обязательно загрузи файл** и установи цену: до этого оплатить его нельзя.

`/orders` — последние 15 заказов и их ID. `/refund 123` — вернуть Stars по заказу 123; после возврата доступ в «Мои покупки» прекращается. `/cancel` — прервать редактирование. `/paysupport` и `/terms` — информация о покупке и поддержке.

## Как работает оплата

1. Покупатель выбирает курс, бот отправляет счёт в валюте `XTR` (Telegram Stars).
2. До списания средств бот проверяет получателя, товар, цену и наличие файла.
3. Только после события `successful_payment` заказ записывается в SQLite с уникальным Telegram charge ID.
4. Бот отправляет файл, а повторная выдача доступна в «Моих покупках». Если отправка не удалась, заказ остаётся в БД и выдачу можно повторить.

Telegram Stars используется потому, что курс — цифровой товар, продаваемый внутри Telegram. Проверь актуальные правила Telegram и условия продажи/возвратов перед запуском. Прямые рублёвые платежи в этой версии не подключены.

## Ограничения и рекомендации

- Используется long polling: запускай **один** экземпляр бота на одну базу.
- SQLite хранится локально. Настрой резервные копии файла БД и безопасное размещение бота 24/7.
- Администратор должен установить `SUPPORT_USERNAME`, разместить понятные условия продажи и обработать обращения о возврате.
- Материалы выдаются как Telegram-документы по `file_id`, поэтому сначала загрузи документы в админ-панели.
- Замена файла меняет материал и для прошлых покупателей; если это нежелательно, создавай новый товар.
- Встроенных веб-панели, аналитики по дням, промокодов, рассылок и нескольких файлов на один товар пока нет.
- Реальный платёж не тестировался: требуется токен, запущенный бот и тестовая покупка в Telegram.
